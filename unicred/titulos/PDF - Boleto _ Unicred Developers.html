PDF - Boleto

Formulário de busca

Sobre

Esta funcionalidade permite consultar e gerar o boleto em formato PDF através da API. O PDF poderá ser consultado enquanto o título estiver em situação Aberto, ou seja, disponível para pagamento. A geração do boleto ocorre sob demanda, sendo realizada no momento da requisição. O retorno da API ocorre de forma unitária, permitindo a consulta de um título por vez.

Personalização do boleto

Cooperados que utilizam a API de geração de PDF poderão personalizar o cabeçalho do boleto com o logotipo da empresa. A parametrização deverá ser solicitada ao Gerente de Relacionamento. Quando houver logotipo configurado: o boleto será apresentado em layout customizado Quando não houver configuração: será utilizado o layout padrão da Unicred

Como usar?

URL:

Usar: https TLS 1.2 
HOMOLOGAÇÃO

GET https://api.e-unicred.com.br/homolog/cobranca/v2/beneficiarios/${id_beneficiario}/titulos/${id_titulo}

PRODUÇÃO

GET https://api.e-unicred.com.br/cobranca/v2/beneficiarios/${id_beneficiario}/titulos/${id_titulo}


Onde:
{Id_beneficiario}, será enviado na planilha de homologação e de produção, que identifica o cooperado beneficiário 
de cobrança.
{Id_titulo}, será gerado pelo sistema de cobrança da Unicred e retornado, pela API de emissão de título, 
com sucesso na emissão.

Cabeçalho da requisição:

Authorization: bearer $TOKEN
cooperativa: $codigo_cooperativa
content-type: application/json
cache-control: no-cache

Exemplo:

curl -X GET
   \ 'https://api.e-unicred.com.br/homolog/cobranca/v2/beneficiarios/B7CEE6BDC9E04C49A7437EC3E750140A/titulos/123asd456qwe789rty'
   \ -H 'cache-control: no-cache'
   \ -H 'apiKey: xxxxx'
   \ -H 'content-type: application/json'
   \ -H 'cooperativa: 0001'
   \ -H "Authorization: bearer f9d93dk211394f9d93dk211394f9d93dk211394f9d93dk211394f9d93dk211394f9d93dk211"
 

Response

Caso o PDF já tenha sido gerado, o corpo do retorno será no formato binário.

HTTP Status:

200 – OK

→ Requisição processada com sucesso.

202 – Accepted

→ Resposta sem corpo, informando o cliente que o processamento ainda está em andamento.

401 – Unauthorized

→ Ocorre quando o token utilizado não é válido para a operação.

403 – Forbidden

→ Ocorre quando o usuário do token utilizado não possui permissão para efetuar a operação.

404 – Not Found

→ Ocorre quando a identificação do título informado na requisição não foi encontrado na base Unicred.

500 – Internal Server Error

→ Ocorre quando há erro interno nos serviços disponibilizados pela Unicred.

Corpo da resposta, quando erro:

{
  "message": "Ocorreu um erro.",
  "timestamp": 4456798441156,
  "httpStatus": 500,
  "url": "http://api.unicred.com.br/servico"
}
